About

If you'd like to know me a little more.

I'm Munazzar, a software developer near Chicago. Currently, most days I work on Adobe Experience Manager and Adobe Learning Manager — the sites, the edge workers behind them and the sign-in that ties them together. I enjoy the whole arc: writing the code, shaping the architecture, and the early conversations where a solution first takes shape.

At work

AEM · Learning Manager · Edge

  • Built a learning platform on AEM Edge Delivery backed by Adobe Learning Manager — catalog, My Learning, course pages and an embedded player.
  • Moved its API proxy to Fastly Compute from Cloudflare Workers, with signed sessions.
  • AEM 6.5 work for AbbVie — SAML sign-in that keeps deep links intact, and a Learning Manager reference-site upgrade.
  • A theming framework that authors control from Universal Editor, plus performance and accessibility fixes.
